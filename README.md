# Water Quality Monitoring Platform - PFE Project

This project was developed as part of my final year (licence en informatique - Big Data & Analyse de données) with a focus on environmental monitoring using IoT and real-time data processing.

## 🌟 Features

- Real-time water quality data visualization
- Integration with IoT sensors (ESP32 + water quality sensors)
- Web dashboard to monitor, manage, and analyze data
- Alerts for abnormal sensor values
- Data storage using MongoDB and MySQL

## 🧰 Technologies Used

- Laravel (Backend)
- Node.js (Data bridge / API)
- Python (Sensor data)
- MongoDB & MySQL (Databases)
- ESP32 (Hardware)
- Ngrok (Local to web tunnel)
